# pencil-puzzles

The registry of every genre. `genres()` lists the compiled-in genres,
`find()` looks one up by id or alias, and `read()` detects the genre of a text
record, ID or JSON envelope. Each genre has a feature named after its id;
`all-genres` enables all of them. The benchmark lives in `examples/`.

See the [root README](../../README.md).
