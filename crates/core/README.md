# pencil-puzzles-core

Shared code for [pencil-puzzles](../../README.md): the `Genre` trait, the
solve loop (`human`) and generator loop (`search`), ratings, work budgets,
the text and ID formats, and the `SplitMix64` random number generator. The
`serde` feature adds serialization to the shared result types.

See [the framework design](../../docs/design/framework.md) and
[the guidelines](../../docs/guidelines.md).
